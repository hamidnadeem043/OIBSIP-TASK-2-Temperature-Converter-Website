# Temperature Converter Website 🌡️

A simple and responsive Temperature Converter built using **HTML**, **CSS**, and **JavaScript**.

This web application allows users to convert temperature values between **Celsius**, **Fahrenheit**, and **Kelvin** with a clean and user-friendly interface.

## How It Works

1. User enters a temperature value.
2. User selects conversion type from dropdown.
3. Clicks the **Convert** button.
4. JavaScript applies the formula.
5. Converted temperature is displayed on screen.


## Conversion Formulas Used

### Celsius to Fahrenheit
F = (C × 9/5) + 32

### Fahrenheit to Celsius
C = (F − 32) × 5/9

### Celsius to Kelvin
K = C + 273.15
